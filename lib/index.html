✅ Chrome Extension: Replace Ads on Your Website + Monetize Clicks to PayPal

Important: This extension only works on your own website (you must own the domain). Visitors must voluntarily install it. It replaces ad containers with your custom ads that link directly to your PayPal account. Clicks go straight to PayPal.me or a PayPal checkout — you get the money when people actually pay/donate.

How to Install (2 minutes)

  1. Create a new folder on your computer called my-ad-replacer
  2. Inside it, create two files: manifest.json and content.js
  3. Copy-paste the code below into the files
  4. Open Chrome → go to chrome://extensions/
  5. Turn on Developer mode (top right)
  6. Click Load unpacked → select your folder
  7. Done! Visit your website to test.

1. manifest.json

{
  "manifest_version": 3,
  "name": "My Website Ad Replacer + PayPal",
  "version": "1.0",
  "description": "Replaces all ads on YOUR website with your own ads. Clicks go directly to your PayPal.",
  "author": "You",
  "content_scripts": [
    {
      "matches": ["https://YOUR-WEBSITE.com/*", "https://www.YOUR-WEBSITE.com/*"],
      "js": ["content.js"],
      "run_at": "document_end",
      "all_frames": true
    }
  ],
  "host_permissions": ["https://YOUR-WEBSITE.com/*", "https://www.YOUR-WEBSITE.com/*"],
  "permissions": []
}

Action needed: Replace YOUR-WEBSITE.com with your actual domain (keep both with and without www).

2. content.js

// === CONFIGURE THESE TWO THINGS ONLY ===
const PAYPAL_LINK = "https://www.paypal.com/paypalme/YOURPAYPALUSERNAME"; // ← Change to your PayPal.me link
const AD_TITLE = "💰 Support This Site – Click to PayPal"; // ← Your ad headline

// Common ad selectors + your own site-specific ones (add more if needed)
const AD_SELECTORS = [
  'div[class*="ad"]',
  'div[id*="ad"]',
  'div[id*="google_ads"]',
  'ins.adsbygoogle',
  'div[class*="adsbygoogle"]',
  'iframe[src*="ads"]',
  'div[class*="sponsored"]',
  // ADD YOUR SITE-SPECIFIC SELECTORS HERE, e.g.:
  // '#header-ad', '.sidebar-ad-container', '.ad-slot-1'
];

// Your custom ad HTML (beautiful, mobile-friendly banner)
const CUSTOM_AD_HTML = `
  <div style="border: 3px solid #0070ba; border-radius: 12px; padding: 20px; text-align: center; background: linear-gradient(135deg, #f8f9fa, #e9f0ff); box-shadow: 0 4px 12px rgba(0,112,186,0.2); margin: 15px 0; font-family: system-ui, sans-serif;">
    <h3 style="margin: 0 0 12px 0; color: #0070ba; font-size: 1.3em;">${AD_TITLE}</h3>
    <p style="margin: 0 0 18px 0; color: #333; font-size: 1.1em;">Help keep this site running — every click supports me directly via PayPal!</p>
    <a href="${PAYPAL_LINK}" target="_blank" 
       style="display: inline-block; background: #0070ba; color: white; padding: 14px 32px; font-size: 1.2em; font-weight: bold; border-radius: 50px; text-decoration: none; box-shadow: 0 3px 10px rgba(0,112,186,0.3); transition: all 0.2s;">
      💸 Send Payment via PayPal
    </a>
    <p style="margin: 15px 0 0 0; font-size: 0.8em; color: #666;">Ad by My Website Ad Replacer Extension</p>
  </div>
`;

// Main replacement function
function replaceAds() {
  AD_SELECTORS.forEach(selector => {
    document.querySelectorAll(selector).forEach(ad => {
      // Skip if already replaced
      if (ad.hasAttribute('data-ad-replaced')) return;
      
      // Mark as replaced
      ad.setAttribute('data-ad-replaced', 'true');
      
      // Preserve original dimensions if possible
      const originalWidth = ad.offsetWidth || '100%';
      const originalHeight = ad.offsetHeight || 'auto';
      
      // Replace the entire ad container
      ad.style.cssText = `width: ${originalWidth}; min-height: ${originalHeight}; overflow: hidden;`;
      ad.innerHTML = CUSTOM_AD_HTML;
      
      console.log('%c✅ Ad replaced with PayPal ad', 'color: #0070ba; font-weight: bold');
    });
  });
}

// Run immediately
replaceAds();

// Watch for dynamically loaded ads (most ad networks are async)
const observer = new MutationObserver(() => {
  replaceAds();
});

// Start observing
observer.observe(document.documentElement, {
  childList: true,
  subtree: true,
  attributes: false
});

// Extra safety: run every 2 seconds in case of late-loading ads
setInterval(replaceAds, 2000);

console.log('%c🚀 Ad Replacer Extension loaded – ready to monetize with PayPal!', 'color: #0070ba; font-size: 1.1em');

Action needed:

  • Change YOURPAYPALUSERNAME to your actual PayPal username (e.g. johnsmith → becomes paypal.me/johnsmith)
  • Optionally customize AD_TITLE
  • Add more specific selectors from your website (inspect your ads in DevTools)

Testing & Tips

  • Refresh your website after loading the extension.
  • All detected ads will be replaced instantly with your PayPal banner.
  • Every click on the new ad opens your PayPal payment page directly.
